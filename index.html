今天，知满科技正式发布面向科学研究与复杂工程研发的旗舰大模型 Micius-27B，并开放在线体验与 API 接入，模型权重后续开放。

Micius（墨子）是知满推出的科学工程大模型系列，以半导体这一知识密集、工程链路复杂、专业工具高度集中的领域作为首个重点实践场景。它是一个懂工程、会工具、能交付的 27B 模型：能够理解工艺文档、电路原理图与芯片版图，生成并调试 RTL 与 EDA 工程代码，自主调用 KiCad 及相关 EDA 工具链完成多步骤工程任务。

通用模型缺少高质量半导体语料、硬件代码数据和专业工具环境；能力较强的闭源模型又无法本地部署。行业需要一个补齐领域知识、能操作专业工具并支持私有化部署的专业模型。

四个方向的专项能力

半导体知识

解答工艺、器件与电路问题，并基于物理原理推理分析。

芯片与电路代码

生成可通过编译与仿真验证的 Verilog、VHDL 与 EDA 脚本。

工程 Agent

在 EDA、KiCad 等专业工具中自主完成多步骤任务。

多模态理解

理解电路图、原理图、版图截图与波形图等工程图像。

从 18 棵知识树到多教师在线蒸馏

Micius 的研发投入主要集中在数据飞轮：团队从 10 个学科视角和 8 个产业与标准视角分别构建半导体知识树，再把权威语料映射到知识节点，每道训练题都能追溯到具体出处。

训练上，七个与 Micius 同尺寸的 27B 领域 Teacher 先完成专项训练，再通过多教师在线蒸馏（MOPD）把能力汇聚到同一个模型。代码与工具调用轨迹都经过沙箱实际执行验证，模型学到的是可运行、可验证的工程行为。

评测数字之外，更接受真实工程检验

Micius Harness 是知满自研的工程 Agent 平台，把模型的行业知识、代码与工具调用能力，与 EDA、KiCad 等专业软件及真实项目相连。工程师用自然语言提出任务，在关键节点确认，并逐项核验源文件、波形、版图和规则检查报告。以下任务均由 Micius 独立完成。

在真实研发场景中持续迭代

更大规模的 Micius 模型预计于近期上线。接下来，Micius 将进入芯片设计企业与晶圆厂的真实研发流程接受检验，以流片结果、签核报告和工程师评审作为最终评价标准；真实任务中暴露的失败案例将定位到知识树的具体节点，让迭代可度量、可追溯。

以半导体为起点，这套“知识树 + 数据合成 + 在线蒸馏 + 工程闭环”的方法，将逐步拓展至材料、能源等更多科学研究与工程研发领域。

Micius 取名自墨子。他既探究光学、力学之理，也研制器械、躬身工程实践。这个名字时刻提醒团队：把知识做深，把工程做透。

欢迎半导体及相关领域的工程师与研发团队试用 Micius、接入 Harness，并提出反馈。
